## Featured project

### 🛢️ Crude Oil Supply Chain & Logistics Analytics
An end-to-end analytics project tracing fuel through a refinery's supply chain,
from inbound crude to outbound product, answering five business questions across
volume, supplier reliability, delivery efficiency, cost, and inventory health.

- **Stack:** SQL (MySQL) · Python · Tableau · Excel
- **Highlights:** 9-table star schema · OTIF reliability scorecards · seasonal
  demand analysis · live interactive Tableau dashboard
- **[Read the case study →](https://prachidabli-data.github.io/crude-oil-case-study.html)**
